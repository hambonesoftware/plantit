Decorative environment images: generated with the built-in image-generation
service for this PlantIt design. Not documentary photographs of user rooms.
Files: assets/sanctuary.jpg, assets/vine-house.jpg, assets/fern-alcove.jpg.
Prompts: sun-washed ivory plaster with dense realistic foliage at page edges,
hanging vines, fern fronds, soft golden light and Gaussian bokeh; distinct
Sunroom, Vine House and Fern Alcove environments; no text or interface.

Font: DM Sans, Google Fonts. See assets/FONT-LICENSE.txt (SIL OFL 1.1).
Headings use the device's Georgia or serif fallback.

Gaussian scene geometry, renderer, camera paths, UI, and scene generator:
created for this PlantIt edition. Decorative plant meshes are represented
by Gaussian primitives; species identification uses the credited photos.

Algorithm reference: Kerbl et al., 3D Gaussian Splatting for Real-Time
Radiance Field Rendering (2023). https://repo-sam.inria.fr/fungraph/3d-gaussian-splatting/
No reference implementation code or model weights are bundled.
